## 二、外网访问配套（三选一，成本差别很大）

摄像头的画面只能在局域网里出流，手机在 4G 下要看到，必须解决"怎么翻出去"。这部分成本取决于你家里现在有什么。

### 方案 A：家里已有常开 Linux 设备 → ~~¥0~~ **已排除**

适用：有 NAS（群晖/威联通）、软路由（OpenWrt/iStoreOS）、树莓派、或常年开机的旧电脑。

**用户已确认：无 NAS。** 若后续翻出闲置的软路由或常开旧电脑，这条随时可以捡回来——它体验最好：免公网 IP、免端口映射、自带 HTTPS 证书、不用改路由器。

### 方案 B：没有，买一台最小 Linux 板 → ¥40~150

| 选项 | 价格 | 说明 |
|---|---|---|
| 玩客云（二手）+ 刷 Armbian | ¥40~60 | 最便宜，功耗 3W，够跑 tunnel |
| 香橙派 Zero 3 | ¥99 | 全新，1GB 内存，官方镜像完善 |
| 树莓派 Zero 2 W | ¥150 | 生态最好，资料多 |
| 树莓派 4B 2GB | ¥350+ | 性能过剩，除非还想跑识别 |

这块钱花得值：一台 3W 的小板子 7×24 跑着，一年电费不到 10 块。

### 方案 C：不想加设备，走 IPv6 直连 → ¥0

| 前提 | 检查方法 |
|---|---|
| 宽带给了公网 IPv6 前缀 | 光猫后台看 WAN 口有没有 240e:/2408: 开头地址 |
| 路由器放行 IPv6 入站 | 大部分路由器默认全封，要手动开 |
| 手机 4G 有 IPv6 | 手机浏览器访问 test-ipv6.com 看 |

国内三大运营商 IPv6 普及率已经很高，但**路由器默认封 IPv6 入站**是常见拦路虎，而且 IPv6 地址会变（要自己做 DDNS）。省了钱，多了折腾。

### 无 NAS 情况下的二选一

| | 方案 B（加板子） | 方案 C（IPv6） |
|---|---|---|
| 一次性成本 | ¥40~99 | ¥0 |
| 域名 | 固定不变，存个书签就行 | IPv6 地址会变，要做 DDNS |
| HTTPS | 自带，手机不报警 | 无，浏览器会提示不安全 |
| 路由器改动 | 不用动 | 要放行 IPv6 入站 |
| ESP32 暴露公网 | 不会，只在内网 | 会，只能靠 Basic Auth 挡 |
| 配置一次后维护 | 基本零维护 | 前缀一变就得管 |
| 折腾程度 | 中（刷机一次） | 中高（还可能要不到 IPv6） |

**结论：推荐方案 B。** ¥40 买的是"以后不用管"，这笔账划算。

做法上两条可选：
- **愿意折腾刷机** → 玩客云二手 ¥40，刷 Armbian，装 cloudflared，功耗 3W
- **想省事** → 香橙派 Zero 3 ¥99，官方镜像烧完就能用

先别急着下单：花 5 分钟用手机连家里 WiFi 打开 `test-ipv6.com`，如果显示没拿到 IPv6 地址，方案 C 直接出局，只能走 B。

## 五、采购避坑清单

1. **型号陷阱**：S3 有 N4R2 / N8R2 / N16R8，只有 N16R8 能舒服跑视频。下单前截图问客服。
2. **别买老 ESP32-CAM（AI-Thinker 那块蓝板）**：¥20 很便宜，但 VGA 只有 5~8fps、没 USB 口要另买 USB-TTL 下载器、发烫严重。省 30 块，多花三天。
3. **充电线 ≠ 数据线**：这是第一大坑。线插上电脑没识别到 COM 口，80% 是线的问题。
4. **电源要独立**：5V/2A 适配器，别用电脑 USB 口供电调试。WiFi 发射瞬间 500mA+ 峰值，压降就复位，表现是"随机重启/花屏/连不上"。
5. **外壳必须塑料/亚克力**：金属壳把 2.4G 信号挡掉一半，表现是"离路由器两米就掉线"。
6. **确认 USB 接口类型**：S3 板子有 Type-C 也有 Micro-USB，买错线白等一周。
7. **散热片别省**：连续推流 S3 和 OV2640 都烫，密闭盒子里几小时降频，画面卡成 PPT。

## 七、Linux 主机到底解决什么问题

**关键认知：这台机器不是"公网服务器"，而是"从家里主动往外连的跳板"。**

家里宽带在运营商 NAT 后面，没有公网 IP，外部设备无法主动连入。但只要有台机器 7×24 开机、主动向公网维持一条长连接，外部流量就能借这条已建好的连接反向流进来。这就是它存在的全部理由。

### 三条通路

| | Tailscale | Cloudflare Tunnel | IPv6 直连 |
|---|---|---|---|
| 一次性成本 | ¥0 | ¥0 | ¥0 |
| 持续成本 | ¥0 | 域名 ¥60/年 | ¥0 |
| 需要 Linux 主机 | 要 | 要 | 不要 |
| 手机端 | 装 App | 浏览器直接开 | 浏览器直接开 |
| HTTPS | 自带（WireGuard） | 自带 | 无，浏览器报警 |
| ESP32 是否暴露公网 | 不会 | 不会 | 会 |
| 域名稳定性 | 固定 | 固定 | 会变，要 DDNS |
| 维护量 | 零 | 零 | 前缀一变就得管 |

### ① Tailscale（推荐先试）

```bash
# Linux 主机
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --advertise-routes=192.168.1.0/24
```

跑完去 Tailscale 后台 → Machines → 该机器 → **Edit route settings** → 批准 `192.168.1.0/24`。

手机装 Tailscale App，登录同一账号打开开关，之后浏览器直接访问 `http://192.168.1.50`（ESP32 局域网 IP）。

原理：Linux 主机当"子网路由器"，把整个局域网通告给 Tailscale 网络，手机连进来就等于接入家里内网。**ESP32 上不用装任何东西，也不用开任何端口。**

免费政策（2026-11 核实，以官网 pricing 页为准）：**$0 永久免费**，最多 **6 个用户**，用户设备数**不设限**，50 个 tagged resources，3 个 ACL 组。家用场景（1 台 Linux 主机 + 1 部手机）远远用不完。

> ⚠️ **iOS 端有个硬门槛**：Tailscale 的 iOS App **在中国大陆区 App Store 不提供**（苹果自 2019 年起在中国大陆、俄罗斯、白俄罗斯三地不上架该应用），搜索会提示"此项目在您所在的国家或地区不可用"。
>
> 解决办法：注册一个非中国区 Apple ID（美区/港区/日区/新加坡），付款方式选"无"，**只在 App Store 里切换账号，不要动 iCloud**，照片备份通讯录都不受影响。装完可切回原账号，App 照常使用，但后续更新可能需再切一次。
>
> 安卓不受此限制，APK 直装。

### ② Cloudflare Tunnel（稳定，需域名）

```bash
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64 -o cloudflared
chmod +x cloudflared
./cloudflared tunnel login
./cloudflared tunnel create homecam
./cloudflared tunnel route dns homecam cam.你的域名.com
./cloudflared tunnel run --url http://192.168.1.50 homecam
```

好处：手机不装任何 App，浏览器打开 `cam.你的域名.com`，自带 HTTPS。
代价：需要一个托管在 Cloudflare 的域名，`.com` 约 ¥60/年，`.top`/`.xyz` 首年十来块。

> 玩客云是 32 位 ARM（Amlogic S805），要下 `cloudflared-linux-arm`；香橙派 Zero 3 是 arm64，用 `linux-arm64`。下错架构会报 `Exec format error`。

### ③ IPv6 直连

零成本、不用买主机，但地址会变（要做 DDNS）、路由器要放行入站、ESP32 直接暴露公网。**省 ¥45，多一堆长期维护**，不划算。

### 按手机系统定方案

| 情况 | 推荐 | 成本 |
|---|---|---|
| **iPhone + 不想注册外区 Apple ID** | **Cloudflare Tunnel** | 域名 ¥60/年 |
| iPhone + 已有/愿意注册外区 Apple ID | Tailscale | ¥0 |
| 安卓手机 | Tailscale | ¥0 |

Cloudflare Tunnel 的核心优势就是**手机端零依赖**：不装 App、不开 VPN 开关，浏览器输网址就能看，存成书签，家人也能看。¥60/年买这份省心对 iPhone 用户是划算的。

Tailscale 的核心优势是免费 + 安全（P2P 直连不经第三方），代价是手机 App 要一直开着 VPN 开关。

### 已知的坑

**Tailscale 在国内的连接质量**：协调服务器和默认中继都在海外。多数家庭宽带能 P2P 打洞直连（速度够看 VGA 视频），但偶有打不通退到海外 DERP 中继的情况，那时候会卡。遇到就换 ZeroTier（国内有节点），或者转 Cloudflare Tunnel。

**Linux 主机的额外价值**：装好 Tailscale/cloudflared 之后，家里的路由器管理页、以后新增的任何设备，手机在外面都能访问。¥45 买的是整个家庭内网的远程入口，不只为这一个摄像头。

## 八、要不要单独买一台 VPS

**结论：只为一个摄像头，不值当；本来就想有台服务器干别的，值。**

### VPS 方案的形态

VPS 有公网 IP，在上面跑 `frps`，家里小板上跑 `frpc` 主动连上去，把 `http://VPS_IP:8080` 的请求转发到 ESP32 的 80 端口。手机浏览器直接访问。

> ❗ **VPS 不能替代家里的那台设备**。VPS 在公网只能做中转站，主动向上连的那一端必须在家里。所以 VPS 路线 = 服务器 + 玩客云两笔钱，而 Cloudflare Tunnel 只要域名一笔。

### 死穴是带宽，不是流量

这个流要多少带宽：VGA 640×480 / 10fps / JPEG 中等质量 ≈ 30KB/帧 → **300KB/s ≈ 2.4Mbps**。

| 方案 | 年费 | 带宽 | 月流量 |
|---|---|---|---|
| 华为云 2核2G | ¥29（新用户） | **2Mbps**（跑不动） | — |
| 阿里云轻量 2核2G | ¥38~68（新用户秒杀） | 200M 峰值 / 不限流量 | 不限 |
| 腾讯云轻量 2核2G4M | ¥99（新用户） | **4Mbps 固定** | 500GB |
| 腾讯云香港 2核4G30M | ¥199（免备案） | 30Mbps | 500GB |

- 2Mbps 的机器跑不动——流本身就要 2.4Mbps
- 4Mbps 一个人看勉强够，两个人同时看或提到 800×600 就得 8Mbps 以上
- 流量不是问题：每天看 2 小时约 65GB/月，500GB 够用
- **隐性成本：续费恢复原价**，首年 ¥29~99 的机器次年通常涨 2~3 倍，认真用就买三年锁价

### 和 Cloudflare Tunnel 的取舍

| | Cloudflare Tunnel | 便宜 VPS + frp |
|---|---|---|
| 年成本 | 域名 ¥60 | ¥38~99 首年，续费翻倍 |
| 要不要域名 | 要 | 不要，IP 直连 |
| 带宽 / 流量 | 不限 | 3~4Mbps / 500~600GB |
| 国内延迟 | 中 | 低（十几毫秒） |
| ICP 备案 | 不需要 | 国内节点要 |
| 维护 | 几乎零 | 系统更新、安全组、防火墙 |
| 附带价值 | 无 | 能建站、跑服务、当图床 |

### 什么情况下买 VPS 是对的

1. **不想买域名** —— VPS 用 IP + 端口访问，省掉域名和备案两道手续
2. **要低延迟** —— 国内节点十几毫秒，比走 Cloudflare 节点顺
3. **本来就想有台服务器做别的**（建站/图床/API/下载机）—— 摄像头只是顺便挂上去

第 3 种情况推荐 **腾讯云香港 2核4G30M ¥199/年**：免备案、30Mbps 够多人看、续费同价。国内节点便宜但要备案 7~20 个工作日，只为一个摄像头不值当走这趟。

## 九、不用服务器也不用常开主机，还有什么办法

**先理清本质**：让外网访问家里的设备，手段只有三类——**直连、中转、主动推送**。不要服务器、不要主机，就只剩**直连**和**主动推送**，这两类都不需要额外设备。

### ① IPv6 直连 + ESP32 自报 DDNS（最优，零设备）

很多人以为 DDNS 得在路由器或 NAS 上跑，**其实 ESP32 自己就能更新域名解析**，一个 HTTPS GET 搞定：

```
https://www.duckdns.org/update?domains=你的子域&token=你的令牌&ipv6=当前IPv6地址
```

| 免费 DDNS | 域名后缀 | 更新间隔 | IPv6 | 国内解析延迟 |
|---|---|---|---|---|
| DuckDNS | duckdns.org | 5 分钟 | ✅ 原生 | ~220ms |
| dynv6 | dynv6.net | 1 分钟 | ✅ 原生 | ~190ms |
| No-IP | ddns.net | 5 分钟 | ❌ 付费才有 | ~280ms |

家用宽带 IP 租约通常 48~72 小时才变一次，5 分钟更新间隔完全够。

链路：手机访问 `xxx.duckdns.org` → DNS 解析到 ESP32 的 IPv6 → 直连，全程不经任何服务器。**成本 ¥0，零设备，延迟最低。**

前提：
- 宽带有 IPv6（三大运营商普及率已高）
- 路由器放行 IPv6 入站（多数默认全封，要手动开）

> ⚠️ **技术坑**：arduino-esp32 的 IPv6 不像 IPv4 那样默认全开，需要在 IDF 层启用 `CONFIG_LWIP_IPV6`、`CONFIG_LWIP_IPV6_AUTOCONFIG`，Arduino IDE 下可能得改 sdkconfig 或改用 ESP-IDF 编译。

### ② 公网 IPv4 + 端口映射 + DDNS

打运营商客服要公网 IP（电信/联通有时给，移动基本不给），路由器做端口映射，ESP32 上报 A 记录，玩法同 ①。

现实：2026 年运营商在往 CGNAT 迁移，电信部分省份新装宽带的公网 IP 比例已降到六成以下。**能要到算赚，要不到不用纠缠。**

### ③ MQTT 推帧（唯一零前提的方案）

不看 IPv6、不看路由器、不看公网 IP，只要有 WiFi。

ESP32 把 JPEG 帧 base64 后发到免费 MQTT broker（巴法云 / EMQX 公共节点），手机端页面用 MQTT.js over WebSocket 订阅同一 topic，收到就塞进 `<img>` 渲染。

- 零服务器、零主机、零配置、完全免费
- 体验降级：**5~8fps、延迟 1~2 秒、VGA 画质**
- 免费 broker 对包大小和流量有限制，画质调高会被拒

适合"看一眼家里有没有事"，不适合长时间盯屏。

### ④ 不新增硬件：路由器自己当穿透网关

路由器是 OpenWrt / iStoreOS / 梅林的话，直接在它上面装 `cloudflared` 或 `frpc`，不用买玩客云。运营商光猫和小米/华为官方固件做不到。

没有能刷的路由器，二手淘一个刷 OpenWrt 也就 ¥30~50，比玩客云还便宜，而且它本来就 7×24 工作。

### 决策顺序

| 家里情况 | 走哪条 | 成本 |
|---|---|---|
| **有 IPv6** | **① IPv6 + DDNS** | ¥0，零设备 |
| 有公网 IPv4 | ② 端口映射 + DDNS | ¥0，零设备 |
| 路由器能刷 OpenWrt | ④ 路由器跑穿透 | ¥0~50 |
| 以上都没有 | ③ MQTT 推帧（体验降级） | ¥0 |
| 不想折腾 | 买成品摄像头 | ¥100~150 |

**先花 5 分钟测 IPv6**：手机连家里 WiFi 打开 `test-ipv6.com`。有就走 ①——成本最低、体验最好，不用服务器、不用主机、不买域名、无月费。没有再往下选。

## 十、本机实测结论（2026-11-04）

> ⚠️ `test-ipv6.com` 是国外站点，国内打不开属正常，**不能据此判断有没有 IPv6**。要看就直接查本机网卡。

### 实测数据

| 检查项 | 结果 |
|---|---|
| 公网 IPv6 地址 | ✅ 有（`2408:` 开头 = 中国联通，前缀 `2408:8214:619:e500::/64`） |
| 地址类型 | 全球单播，路由通告下发，另有多个临时地址（隐私扩展，正常） |
| IPv6 出口连通性 | ✅ `ping -6` 淘宝 8ms / 百度 10ms，0 丢包 |
| 路由器放行入站 | ⏳ 待手机 4G 端到端验证 |

查询命令（Windows）：
```bash
ipconfig            # 看「IPv6 地址」那行，240e/2408/2409 开头即为公网地址
ping -6 www.baidu.com   # 通了说明出口正常
```

国内段归属：电信 `240e:` / 联通 `2408:` / 移动 `2409:` / 教育网 `2001:da8:`。只有 `fe80::` 开头的是链路本地地址，不算。

### 端到端验证方法

电脑上起个临时服务，手机**关 WiFi 用 4G** 访问电脑的 IPv6 地址：

```bash
# 电脑上（监听 IPv6）
python -m http.server 8080 --bind ::

# 手机上访问（方括号不能省，这是 IPv6 URL 的写法规定）
http://[电脑IPv6地址]:8080
```

打不开先用管理员 PowerShell 放行防火墙：
```powershell
New-NetFirewallRule -DisplayName "IPv6 Test 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
Remove-NetFirewallRule -DisplayName "IPv6 Test 8080"   # 测完删除
```

### 若入站验证通过，方案锁定

- **采购单第 9 项（常开 Linux 板 ¥45）可以去掉**，落地价降到 **约 ¥110**
- 链路：`手机 4G ──IPv6 直连──→ ESP32 ──→ 画面`，中间无服务器、无中转、无第三方
- 域名：DuckDNS 免费二级域名，ESP32 自己上报 AAAA 记录
- 固件要做的事：上电取 IPv6 → 上报 DuckDNS → 开 HTTP 服务（带 Basic Auth）→ 手机访问出画面，全部在一块板子上跑完

## 十一、节点小宝方案（2026-11-04 实测通过，当前采用）

### 结论

**零成本跑通了。手机 5G 经 P2P 直连家里电脑，实测 7.8 fps（VGA 640×480）。**

比 Cloudflare（2.6~4.7fps 且不稳）和买 VPS（¥99/年）都划算。

### 架构

```
手机 5G ──P2P 直连──> 家里的设备（玩客云/电脑）──> ESP32
```

节点小宝不是普通的内网穿透，它优先走 **P2P 打洞直连**，打不通才回落转发。

### 免费版额度（关键）

| 通道 | 额度 | 视频可用性 |
|---|---|---|
| **P2P 直连** | **不限速、不限流量** | ✅ 当前走的就是这条 |
| 转发/中转 | 2~4Mbps + **1GB/月** | ⚠️ 看视频一小时就烧完 |

所以**必须确认走的是 P2P**。判断方法：帧率能到 7fps 以上就是 P2P；卡在 1~3fps 说明在走转发。

### 本项目踩到的通道限制

**节点小宝的 P2P 通道不支持长时间保持的 HTTP 流式响应**，会掐断连接（页面一直停在「重连中」）。

但**普通的短请求完全正常**——单张 `/snap` 能拿到图。

所以固件改用**拉模式**：每帧单独发一个 HTTP 请求，不依赖长连接。

### 实测数据

| 项目 | 结果 |
|---|---|
| 手机经 P2P 访问 `/snap` | ✅ 出图 |
| 手机访问流式页面 `/` | ❌ 一直重连中 |
| 手机拉模式播放页 | ✅ **7.8 fps** |
| 电脑本机经组网 IP 拉流 | 460KB / 3 秒 ≈ 12fps |
| 组网 IP 段 | `100.66.1.x`（电脑 .2，手机 .1） |

### 配置要点

1. 电脑/玩客云装客户端，手机装 App，**登录同一账号**
2. 加入「私有网络」组网
3. 手机上查电脑的组网 IP（形如 `100.66.1.2`）
4. 浏览器访问 `http://100.66.1.2:8080`
5. 注意：虚拟网卡叫 `NodeBabyLink`，其本机地址是 `10.222.222.1`，**但手机要用 100.66.1.x 那个组网地址**

|---|---|---|
| 服务器 | ¥99/年 | **¥0** |
